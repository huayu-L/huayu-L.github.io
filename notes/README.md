# notes / 笔记文件夹

把 Markdown 笔记直接放进这个文件夹，提交并上传到 GitHub，网站就会自动把它们列出来。

这个文件不会显示在网站上，以 `.` 或 `_` 开头的文件和文件夹也不会显示。

## 添加一篇笔记

1. 新建一个 `.md` 文件，文件名随意，例如 `my-first-note.md`。
2. 在文件开头写一段可选的信息（frontmatter）。
3. 提交并推送到 `main` 分支。
4. 打开网站刷新即可。

### 推荐的文件头

```yaml
---
title: 我的第一篇笔记
date: 2026-10-27
tags:
  - 随笔
  - 学习
description: 一两句话介绍这篇笔记。
---
```

只有 `title` 建议填写，其他都可以省略：

- **title**：文章标题。省略时会使用正文里第一个 `# 标题`；再没有就用文件名。
- **date**：写作日期，格式为 `YYYY-MM-DD`。省略时会尝试从文件名开头读取，例如 `2026-10-27-随笔.md`。
- **tags**：标签，可以写成 YAML 列表，也可以写成 `[随笔, 学习]` 或 `随笔, 学习`。没有标签时，子文件夹名会自动作为标签。
- **description**：摘要，会显示在笔记卡片上。省略时会取正文第一段。
- **draft: true**：草稿，不会显示在网站中。

## 文件名与文件夹

文件名可以使用中文。可以用日期开头，方便排序：

```text
notes/
├── welcome.md
├── 2026-10-27-今日随想.md
├── 学习/
│   └── 线性代数笔记.md
└── images/
    └── photo.jpg
```

子文件夹会自动成为标签。`README.md`、以 `_` 开头的模板文件和 `drafts/` 文件夹不会被展示。

## 插入图片

把图片放在 `notes/images/`，然后在 Markdown 中写相对路径：

```markdown
![图片说明](images/photo.jpg)
```

如果笔记在子文件夹里，也可以使用相对于这篇笔记的路径，例如 `../images/photo.jpg`。

## 关于 `_index.json`

网站正常情况下会通过 GitHub API 自动读取 `notes/` 下的所有 Markdown 文件，**添加新笔记时不需要修改 `_index.json`**。

这个文件只是网络无法访问 GitHub API 时的后备目录，里面保存着示例笔记的信息。如果你删除或重命名了示例笔记，又希望离线目录保持准确，可以同步修改它。

## 模板

可以复制 `_template.md` 作为新笔记的起点。模板以下划线开头，所以不会被展示。
